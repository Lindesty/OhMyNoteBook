# 模块03：从字典到并发字典

## 概述

本模块通过一个实际案例演示如何将基于 `Dictionary` 的应用程序改造为并发安全的版本。你将学习到：

- 为什么仅仅将 `Dictionary` 替换为 `ConcurrentDictionary` 是不够的
- 如何处理多线程环境下的数据不确定性问题
- 并发集合中 "Try" 模式的重要性

本模块的核心收获是：**在使用并发集合时，必须以并发思维来设计代码逻辑**。

---

## 演示应用：SellShirts

### 应用场景

SellShirts 是一个模拟 Geek Clothing Company 一天营业的演示程序。销售人员销售 T 恤，库存存储在字典中。初始版本是单线程应用，需要改造成并发版本。

### 基础类型

#### TShirt 类

T 恤实体类，包含编码、名称和价格：

```csharp
public class TShirt
{
    public string Code { get; }
    public string Name { get; }
    public int PricePence { get; }
    
    public TShirt(string code, string name, int pricePence)
    {
        this.Code = code;
        this.Name = name;
        this.PricePence = pricePence;
    }
    
    public override string ToString() 
        => $"{Name} ({DisplayPrice(PricePence)})";

    private string DisplayPrice(int pricePence)
         => $"${pricePence/100}.{pricePence%100:00}";
}
```

#### TShirtProvider 类

提供公司可销售的 T 恤列表。使用 `ImmutableArray` 存储，因为列表内容固定不变：

```csharp
using System.Collections.Immutable;

public static class TShirtProvider
{
    public static ImmutableArray<TShirt> AllShirts { get; } = ImmutableArray.Create(
        new TShirt("igeek", "IGeek", 500),
        new TShirt("bigdata", "Big Data", 600),
        new TShirt("ilovenode", "I Love Node", 750),
        new TShirt("kcdc", "kcdc", 400),
        new TShirt("docker", "Docker", 350),
        new TShirt("qcon", "QCon", 300),
        new TShirt("ps", "Pluralsight", 60000),
        new TShirt("pslive", "Pluralsight Live", 60000)
    );
}
```

> **为什么使用 ImmutableArray？**
> - 不可变集合一旦创建就无法修改内容
> - 不可变集合与并发集合一样，天然是线程安全的
> - 使用 `ImmutableArray.Create()` 方法在创建时一次性填充数据

#### Rnd 工具类

封装随机数生成的静态工具类：

```csharp
public class Rnd
{
    private static Random _generator = new Random();
    
    // 生成 0 到 max-1 之间的随机整数
    public static int NextInt(int max) => _generator.Next(max);
    
    // 以指定概率返回 true
    public static bool TrueWithProb(double probOfTrue)
        => _generator.NextDouble() < probOfTrue;
}
```

### 库存控制器（单线程版本）

`StockController` 是应用的核心，管理 T 恤库存：

```csharp
public class StockController
{
    private Dictionary<string, TShirt> _stock;

    public StockController(IEnumerable<TShirt> shirts)
    {
        _stock = shirts.ToDictionary(x => x.Code);
    }
    
    // 销售衬衫：从库存中移除
    public void Sell(string code)
    {
        _stock.Remove(code);
    }
    
    // 随机选择一件衬衫供顾客浏览
    public TShirt SelectRandomShirt()
    {
        var keys = _stock.Keys.ToList();
        if (keys.Count == 0)
            return null;    // 所有衬衫已售完

        Thread.Sleep(Rnd.NextInt(10));  // 模拟顾客思考时间
        string selectedCode = keys[Rnd.NextInt(keys.Count)];
        return _stock[selectedCode];    // 使用索引器查找
    }
    
    public void DisplayStock()
    {
        Console.WriteLine($"\r\n{_stock.Count} items left in stock:");
        foreach (TShirt shirt in _stock.Values)
            Console.WriteLine(shirt);
    }
}
```

> **设计要点**：`_stock` 字典是私有字段，外部无法直接访问。良好的封装有助于在并发环境中确定哪些线程可能干扰数据。

### SalesPerson 类

销售人员类，模拟一天的工作：

```csharp
public class SalesPerson
{
    public string Name { get; }
    
    public SalesPerson(string name)
    {
        this.Name = name;
    }
    
    public void Work(TimeSpan workDay, StockController controller)
    {
        DateTime start = DateTime.Now;
        while (DateTime.Now - start < workDay)
        {
            var result = ServeCustomer(controller);
            if (result.Status != null)
                Console.WriteLine($"{Name}: {result.Status}");
            if (!result.ShirtsInStock)
                break;
        }
    }
    
    public (bool ShirtsInStock, string Status) ServeCustomer(
        StockController controller)
    {
        TShirt shirt = controller.SelectRandomShirt();
        if (shirt == null)
            return (false, "All shirts sold");

        Thread.Sleep(Rnd.NextInt(30));  // 顾客做决定的时间

        // 顾客有 20% 的概率购买
        if (Rnd.TrueWithProb(0.2))
        {
            controller.Sell(shirt.Code);
            return (true, $"Sold {shirt.Name}");
        }
        return (true, null);
    }
}
```

## 添加并发：问题与解决

### 第一步：引入并发

公司扩张，新增两名销售人员。需要让他们同时工作：

```csharp
static void Main(string[] args)
{
    StockController controller = new StockController(TShirtProvider.AllShirts);
    TimeSpan workDay = new TimeSpan(0, 0, 0, 0, 500);

    // 使用 Task 实现并发
    Task task1 = Task.Run(() => new SalesPerson("Kim").Work(workDay, controller));
    Task task2 = Task.Run(() => new SalesPerson("Sahil").Work(workDay, controller));
    Task task3 = Task.Run(() => new SalesPerson("Chuck").Work(workDay, controller));
    Task.WaitAll(task1, task2, task3);

    controller.DisplayStock();
}
```

### 第二步：替换为 ConcurrentDictionary

将 `Dictionary` 替换为 `ConcurrentDictionary`：

```csharp
// Before
private Dictionary<string, TShirt> _stock;
_stock = shirts.ToDictionary(x => x.Code);

// After
private ConcurrentDictionary<string, TShirt> _stock;
_stock = new ConcurrentDictionary<string, TShirt>(
    shirts.ToDictionary(x => x.Code));
```

> **注意**：`ToDictionary()` 返回的是标准字典，需要通过构造函数将其转换为 `ConcurrentDictionary`。

### 问题一：Remove 方法不存在

`ConcurrentDictionary` 没有 `Remove` 方法，只有 `TryRemove`：

```csharp
// Before
public void Sell(string code)
{
    _stock.Remove(code);
}

// After
public bool Sell(string code)
{
    return _stock.TryRemove(code, out TShirt shirtRemoved);
}
```

`TryRemove` 返回布尔值表示是否成功移除，通过 out 参数返回被移除的项。

### 问题二：运行时异常

代码编译通过，但运行时抛出异常：**"Key not found in dictionary"**

**原因分析**：

```csharp
public TShirt SelectRandomShirt()
{
    var keys = _stock.Keys.ToList();      // 时刻1：获取键列表
    if (keys.Count == 0)
        return null;

    Thread.Sleep(Rnd.NextInt(10));         // 时刻2：等待期间...
    string selectedCode = keys[Rnd.NextInt(keys.Count)];
    return _stock[selectedCode];           // 时刻3：尝试查找
}
```

在多线程环境中：
1. 时刻1：线程A获取了键列表，包含 "bigdata"
2. 时刻2：线程B售出了 "bigdata"，将其从字典中移除
3. 时刻3：线程A尝试查找 "bigdata"，但已不存在，抛出异常

### 解决方案：使用 TryGetValue

不能假设键一定存在，应该使用 `TryGetValue`：

```csharp
public (SelectResult Result, TShirt Shirt) SelectRandomShirt()
{
    var keys = _stock.Keys.ToList();
    if (keys.Count == 0)
        return (SelectResult.NoStockLeft, null);

    Thread.Sleep(Rnd.NextInt(10));
    string selectedCode = keys[Rnd.NextInt(keys.Count));
    
    bool found = _stock.TryGetValue(selectedCode, out TShirt shirt);
    if (found)
        return (SelectResult.Success, shirt);
    else
        return (SelectResult.ChosenShirtSold, null);
}
```

定义枚举表示三种可能的结果：

```csharp
public enum SelectResult { Success, NoStockLeft, ChosenShirtSold }
```

### 问题三：重复销售

修复查找问题后，出现新问题：同一件衬衫被售出多次！

**原因**：在检查衬衫和销售衬衫之间存在时间窗口：

```csharp
TShirt shirt = controller.SelectRandomShirt();  // 时刻1：找到了衬衫
Thread.Sleep(Rnd.NextInt(30));                    // 时刻2：等待期间...
controller.Sell(shirt.Code);                      // 时刻3：销售时可能已被其他线程售出
```

### 最终解决方案

修改 `Sell` 方法返回布尔值，并在调用处检查结果：

**StockController.cs（并发版本）**：

```csharp
public class StockController
{
    private ConcurrentDictionary<string, TShirt> _stock;

    public StockController(IEnumerable<TShirt> shirts)
    {
        _stock = new ConcurrentDictionary<string, TShirt>(
            shirts.ToDictionary(x => x.Code));
    }
    
    public bool Sell(string code)
    {
        return _stock.TryRemove(code, out TShirt shirtRemoved);
    }
    
    public (SelectResult Result, TShirt Shirt) SelectRandomShirt()
    {
        var keys = _stock.Keys.ToList();
        if (keys.Count == 0)
            return (SelectResult.NoStockLeft, null);

        Thread.Sleep(Rnd.NextInt(10));
        string selectedCode = keys[Rnd.NextInt(keys.Count)];
        
        bool found = _stock.TryGetValue(selectedCode, out TShirt shirt);
        if (found)
            return (SelectResult.Success, shirt);
        else
            return (SelectResult.ChosenShirtSold, null);
    }
    
    public void DisplayStock()
    {
        Console.WriteLine($"\r\n{_stock.Count} items left in stock:");
        foreach (TShirt shirt in _stock.Values)
            Console.WriteLine(shirt);
    }
}
```

**SalesPerson.cs（并发版本）**：

```csharp
public (bool ShirtsInStock, string Status) ServeCustomer(
    StockController controller)
{
    var result = controller.SelectRandomShirt();
    TShirt shirt = result.Shirt;
    
    if (result.Result == SelectResult.NoStockLeft)
        return (false, "All shirts sold");
    else if (result.Result == SelectResult.ChosenShirtSold)
        return (true, "Can't show shirt to customer - already sold");

    Thread.Sleep(Rnd.NextInt(30));

    if (Rnd.TrueWithProb(0.2))
    {
        bool sold = controller.Sell(shirt.Code);
        if (sold)
            return (true, $"Sold {shirt.Name}");
        else
            return (true, $"Can't sell {shirt.Name}: Already sold");
    }
    return (true, null);
}
```

## 核心概念：并发集合的不确定性

### 核心原则

在并发环境中，**你无法确定集合当前的状态**，因为其他线程可能在任何时候修改集合。

### Dictionary vs ConcurrentDictionary 方法对比

| 操作 | Dictionary | ConcurrentDictionary |
|------|------------|---------------------|
| 查找 | `dict[key]` 或 `TryGetValue` | 优先使用 `TryGetValue` |
| 移除 | `Remove(key)` | `TryRemove(key, out item)` |
| 添加 | `Add(key, value)` | `TryAdd(key, value)` |

### 为什么 ConcurrentDictionary 只有 Try 方法？

`Try` 方法的设计允许操作失败，而不会抛出异常：

- `TryGetValue`：查找可能失败，因为其他线程可能已移除该项
- `TryRemove`：移除可能失败，因为其他线程可能已移除该项
- `TryAdd`：添加可能失败，因为其他线程可能已添加相同键

### 设计模式

**避免使用**：假设知道集合状态的方法
- `dict[key]`（索引器）
- `Remove(key)`

**推荐使用**：不假设状态、允许失败的方法
- `TryGetValue`
- `TryRemove`
- `TryAdd`

## 要点总结

1. **仅仅替换集合类型是不够的**：将 `Dictionary` 替换为 `ConcurrentDictionary` 只是第一步，还需要调整代码逻辑。

2. **并发环境的不确定性**：在多线程环境下，集合的状态可能在任何时刻被其他线程改变，不能假设之前的检查结果仍然有效。

3. **优先使用 Try 方法**：并发集合的方法设计为允许操作失败，应使用 `TryGetValue`、`TryRemove`、`TryAdd` 等方法，并在代码中处理失败情况。

4. **封装的重要性**：将并发集合封装在类内部，限制外部访问，有助于追踪可能的并发问题。

5. **不可变集合的作用**：对于不变化的数据（如商品目录），使用 `ImmutableArray` 等不可变集合，天然线程安全，无需额外同步。

6. **测试的挑战**：并发问题可能不会每次都出现，需要多次运行测试，考虑各种线程调度情况。

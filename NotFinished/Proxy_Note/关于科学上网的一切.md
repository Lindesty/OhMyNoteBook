# 什么是“墙”，为什么有“墙”

“墙”是指“防火长城”，英文全称“Great Fire Wall”(GFW)

- 来源

08年前的网络审查制度不是特别完善，因为某些政治因素，我国建立起网络审查制度(境内所有网站的数据都是被审查的，甚至还有自我排查)，部署了防火长城，来阻挡大陆互联网用户访问某些境外网站和服务

- “导火索”

08年前奥运会前夕恐怖组织在Facebook上策划、协调并且实施了对我国部地区的一个恐怖袭击，中国政府当时要求Facebook配合审查，以及再次出现此类事件，但Facebook以尊重保护用户隐私的理由拒绝了中国政府的要求，同时Google也以同样的理由拒绝了中国政府的要求，而中国政府不会让不愿意配合的外国公司在中国开展业务，于是一大批的外国服务被封锁。

- 作用

主要在于分析和过滤境外资讯和互相访问

# GFW的工作原理，以及如何突破封锁

## 在没有GFW的情况下

![正常网络通讯](./images/%E6%AD%A3%E5%B8%B8%E7%9A%84%E7%BD%91%E7%BB%9C%E9%80%9A%E8%AE%AF.svg)

本地计算机发出一个数据包，经由本地网络，接入骨干网，经由DNS域名解析成真实的IP地址，到达国际出口最后接入到对应的服务器服务器对你的数据进行处理，然后返回一个数据包，发给你的计算机。

## GFW封锁的手段

### 1. DNS污染

![DNS污染](./images/DNS%E6%B1%A1%E6%9F%93%E5%B0%81%E9%94%81.svg)

解析错误地址或不解析
> 如图，在某些地区GitHub被指向反诈中心
![github被污染](./images/GitHub%E8%A2%ABDNS%E6%B1%A1%E6%9F%93.webp)

### 2. 关键字阻断

由于http通讯过程中有部分明文内容，GFW会探测http流量的内容，一但探测到关键词就会中断连接

### 3. 端口阻断

GFW会在某些特定的IP服务器的主机的特定端口进行端口阻断，来切断VPN或SSL的连接，如“443”，“22”这些端口。

### 4. 直接屏蔽IP

经过一些时间的动作，GFW还将大量的IP地址进行屏蔽，导致很多的国外网站被封锁

### 5. 特征检测

GFW会去检测流量的意图，必要时还会有人工干预

# 突破封锁的手段

根据GFW的工作原理，可知，只要GFW不探明我数据包的真实意图，那么我可以通过连接一台符合GFW认为合理的服务器作为中转，来替代我去做做访问最后把结果，期间整个过程都要加密。

### 部分加密：SSH与VPN

![vpn&SSH](./images/VPN%E4%B8%8ESSH.svg)

本地网络上的放松发送一个请求建立加密通道的数据包接入骨干网，进行域名解析，GFW认为这是一台允许访问的国外服务器，放行后，数据包经过中转服务器后解密出我真实想要访问的地址，转到那个地址，在接收到服务数据后返回给中转服务器，再经过GFW传回本地计算机。

在这各情况中，GFW无法看到连接中的关键字，在DNS解析时，GFW会认为我访问的对象是允许的服务器，DNS也能正常解析。

由于SSH与VPN本就不是为这种场景设计，因此其流量有着明显的特征，因此GFW对这种流量做了两件事：

1. 屏蔽掉VPN的通讯端口，政企VPN需要申报审核
2. 对提供VPN服务的服务器IP进行指封锁

### 全加密

通过把代理服务器拆分成本地和远程来实现经过GFW的流量全部加密，从而消除流量特征

![全加密](./images/SS%E5%85%A8%E5%8A%A0%E5%AF%86.svg)

从本地计算机发出一个数据包给本地的Shadowsocks服务器(指手机、电脑上的软件或软路由 )发送数据加密请求，通过骨干网到达国际出口，因为GFW探测不到具有流量具有明显的特征，所以会放行，之后到达你的远程中转服务器(远程Shadowsocks服务器，可以是自己的vps，也可以是机场的服务器)， 然后解密数据转发到国外服务，将响应的数据通过相同的过程发送回来

SS、SSR、v2ray等基本就是通过这种逻辑，在过墙时通过加密消除特征来突破墙的封锁，而因相比翻墙的流量，超过99%的流量都是正常的需求

# 本地科学上网方式的选择

### VPN(基本死了)

最早是由某些公司各部门在不同的地区，有私密通讯的需求，但是专线非常贵，这时VPN就可以满足这各需求，通过在现有网络上使用隧道协议创建一个虚拟的点对点连接，可以远程访问专用网络中可用的资源(如在分公司通过VPN访问公司总部的NAS)

从其来源可知，从被开发出来开始，VPN就不是为翻墙而设计的，只是这种端对端加密的方式正好不会被GFW发现，但是由于其加密特征特别明显，现已经被GFW完美的探测并封锁

政企通过审核才可与海外服务器建立VPN，与个人用户无缘

- VPN的特点：
  大部分VPN工作在OSI模型中的第三层及以 下——网络层，因此其拥有真正的实现“全局代理”的能力
- 常用协议：
  PPTP、L2TP、openVPN、SSTP等

### SS协议以及一众的衍生品

包括SSR、V2ray、Trojan等协议

需要用到一些软件来应用这些加密算法，如“Quantumult X”、“ShadowRocket”、“V2Ray”、“Clash”、“Surge”等

选择加密协议与加密算法需要根据自己的需求来，不是越新的协议就越好，如最新的“Vmess”协议对算力有较高的要求，不适合跑在老设备上，而加密也会导致延迟增加

大多数软件都没有底层权限(Socks在OSI七层协议的第五层,即会话层下运行)，只能代理应用层的网络流量，就算打开“全局代理”，也只是接管了“系统代理”(大部分软件上网都走系统代理，有一些软件不会过系统代理(如微软商城，UWP应用)，甚至有着自己的驱动连接网络)，可以通过TUN／TAP工具强行接管指定程序的网络流量走虚拟网卡，或在硬件层模拟一个虚拟网卡强行接管所有的出口流量

### 使用路由器做为代理服务器

路由器做为本地网络接入互联网的最后一个环节，并且独立于你的电脑，所以可以无视你电脑的代理规则强行接管所有的网络流量

路由器中用来突破限制的协议与软件基本一致，路由器相比软件来说，可以应用于无法安装加解密软件的网络设备，如Apple TV、XBOX ，PS5等

但是路由器的算力其实只能满足最基础的路由功能，在进行大量的加密解密计算时，可能会导致网络通讯的卡顿、带宽跑不满、当机等情况，购买软路由就可以解决性能太差的缺点，但是软路由价格较高，配置相对繁琐，稳定性较差，且日常维护相对繁琐(固件更新、更换节点都要进入后台调试)

### 网关模式(DHCP接管内网)

关闭路由器的DHCP，使用Surge的DHCP模式接管局域网内所有流量

# 境外线路的选择

## CN2线路

是中国电信下一代承载网(ChinaNet Next Carrying Network)的缩写,使用了扁平化设计，和使用多协议标签交换（MPLS）承载多业务数据。优点是减少了网络复杂性，兼容现有各种主流网络技术，能降低网络成本，在提供IP业务时能确保QoS和安全性，具有流量工程能力。

> QoS提供了针对不同用户或者不同数据流采用相应不同的优先级，或者是根据应用程序的要求，保证数据流的性能达到一定的水准(就是能识别网络中不同流量的不同需求，使需要低延时的流量(如对带宽没有大要求但是对延迟有很大要求的游戏通讯数据)，与对需要大带宽，但对于延延迟没有特别需求的数据(流媒体数据)同时得到满足。

普通人连接外服会卡正是因为其使用的网络是旧的163骨干网，而旧的163骨干网是没有QoS有功能的

而CN2又可以分为“CN2GT「Global Transit」”和“CN2GIA「Global Internet Access」”

CN2 GT和CN2 GIA保证国家间的传输在CN2骨干网(59.43节点)上进行，即国际出口为59.43
CN2 GT的省级出口是202.97节点，国际出口只有59.43。比如南京电信->上海电信，CN2GT是202.97，CN2GIA是59.43；

如果该省有CN2节点，CN2 GIA线路可以直接访问CN2节点。例如，自江苏南通以来，该省有CN2节点(江苏南京)，因此CN2 GIA线路直接与CN2节点(59.43)相连，然后从上海出口；

如果本省没有CN2节点，CN2GIA线路就近接入北上广的202.97节点，再接入当地的59.43节点。比如从安徽芜湖电信开始，先进入上海202.97，再进入59.43，最后出口。

而有些CN2可能是单向的，可能出现出国走的是CN2线路，而回来走的是163线路

## 走BGP协议的线路

边界网关协议（英语：Border Gateway Protocol，缩写：BGP）是互联网上一个核心的去中心化自治路由协议。

BGP协议一般也叫多线机房，BGP可以自动识别你的线路(是电信、移动、联通)，并且自动使用最适合你连接服务的线路，在当前网络不佳的时候，还会自动切换到其他的线路来连接服务器，

## 国外的云服务提供商

可以换IP，带宽大，但支付时需要用到双币信用卡，且国外的去服务提供商都不是针对国内市场来开展业务的，时不时会抽风。

1. GCP

Google Cloud Platform ( GCP )是一套云计算服务，运行在 Google 内部用于其最终用户产品（例如Google Search、Gmail、Google Drive和YouTube）的同一基础架构上，提供基础架构即服务、平台即服务和无服务器计算环境。

流量非常贵

2. AWS

Amazon Web Services, Inc. ( AWS ) 是Amazon的子公司，以按需付费的方式向个人、公司和政府提供按需 云计算 平台和API

流量较少

2. Azure

Microsoft Azure 是微软的公用云端服务 (Public Cloud Service) 平台，是微软在线服务 (Microsoft Online Services) 的一部分

申请比较麻烦

## PCCW

电讯盈科有限公司（英语：PCCW Limited）是一家以香港为总部的环球公司，在电讯、媒体、信息技术服务方案、物业发展及投资以及其他业务均持有权益。

到大陆的线路走的是PCCW接的直连，线路还包括HKT、HKBN等，线路相比其它非常稳定

## IPLC & IEPL

IPLC是"International Private Leased Circuit" 的缩写，即“国际私用出租线路”，也称作固接专线（简称专线）是用来连接两个地区的对称电信线路。

价格奇贵，带宽低，流量小，但IPLC不过GFW审查
![专线价格](./images/%E4%B8%93%E7%BA%BF%E4%BB%B7%E6%A0%BC.webp)

IEPL是「international ethernet private line」的缩写，是利用SDH的传输网络和覆盖能力，提供通达全球以太网的低延迟和高可靠性专线连接：最新的EoSDH技术确保了延迟和可靠性要求，并提供与IPLC相同的性能指标增强的网络灵活性和可扩展性，相比IPLC延迟更低,由于TDM「Time Division Multiplexing」导致的抖动也会减小

因为内网的需求一般是某些大企业、跨国机构所使用，要求网络有着低时延和可靠性，国际专线节省了大量的跳转和转发，最大程度保证了可靠性和稳定性，所以内网线路严格来说不算翻墙，因为内网线路不受到GFW的审查

IPLC和IEPL都是通过内网线路通信的，不转到公网，IPLC是通过物理层把两个点连接组成局域网，IEPL是通过数据链路层连接点对点或多点对多点连接起来的，相要连接互联网还需要接入当地的机房，再接入互联网

不同于全局IPLC，使用机场的IPLC时，数据包会先经过你的本地网络接入小区网络到互联网，然后才以连接到IPLC中转节点，这个时候才进入专线，然后数据发送到内网的外中转节点，再接入公网访问服务

> 全局IPLC：发出的数据包直接进入内网专线，不经过跳发，直接传输到专线的出口

机场的IPLC线路会受到机房、接入用户数量、是不是超售、用户本地网络的影响

# 机场orVPS

## VPS

主要有 Linode、Vultr、Bandwagon等，选好VPS后就可以挑选线路了，若用伪装的方式，还需要买域名、改A记录等，若用比较旧的加密协议，可能使用几天就会被封，因为这几年GFW对一些海外的服务器IP做了统计和监控
简单的SS或SSR加密对于个人用户来说很容易被封，就需要用比较新的加密方式如V2Ray，但这些对新手来说不是很友好，部署起来难度大，你可能需要知道什么是Vmess、Websocket+TLS、Trojan

是指拥有大量VPS，为中国网民提供特殊、加密上网方式节点的平台网站

机场选择：

3. 测试的时间一定要在周末的晚上，这个时间点用的人最多，最具代表性

# 加密协议

shadowsocks、v2ray的vmess、trojan、websocket + tls

前文中提到，加密的意义就是不让GFW发现数据流量的特征，从而“不被墙”
，GFW可能会从IP、端口、数据量大小和长短、数据头、TCP长连接时长来判断，甚至还通过被动监听和主动嗅探、以及在政治敏感期的人工干预。

以上的内容都只是推测，没有人知道GFW到底用什么方式来探测、判断和封锁的

- shadowsocks

要求的性能不高，目前还是体验最好，最快速的协议，因拥有最快的RTT，因为其在握手的时候用时最短

- v2ray

是个极具弹性的平台，支持的协议和算法多，部署复杂，因某些机制导致握手次数相比shadowsocks更多，且由于v2ray原创的vmess协议+TLS两次加密，对设备的资源占用比较高，但目前来说，Vmess+Websocket+TLS+Web的方式是最稳定的方式之一

- trojan

解决了v2ray复杂、部署难度大的问题，通信协议只有一种——Websocket+TLS，可看作是v2ray的简化版，但不支持反代理

# 非主流的翻墙方式

这里的“非主流”指的并不是使用的人少，而是使用起来的稳定性差，延迟高、带宽低。

那些小厂做的客户端(“xxVPN”“xx加速器”)，虽然名子叫做“VPN”但内部根本不是VPN的协议，一般都是内封shadowsocks的客户端

- wireGuard

VPN工具主要采用的是TCP通讯协议，而WireGuard采用UDP通讯

> TCP协议
> 需要本地和远程多次握手，并且建立长连接，验证每一次通讯确保数据按顺序完整到达并处理，但TCP容易被GFW通过发送reset包来阻断

> UDP协议
> 只负责发送数据包，不管对方是否能接收，所以GFW没有有效的手段来阻断

但是UDP流量被QoS限速的极为普遍的情况

# 中国大陆境内翻墙安全

> 《计算机信息网络国际互联网安全保护管理办法》
> 第5条规定：
> 任何单位和个人不得利用国际互联网制作、复制、查阅和传播下列信息：
> （一）煽动抗拒、破坏宪法和法律、行政法规实施的；
> （二）煽动颠覆国家政权，推翻社会主义制度的；
> （三）煽动分裂国家、破坏国家统一的；
> （四）煽动民族仇恨、民族歧视，破坏民族团结的；
> （五）捏造或者歪曲事实，散布谣言，扰乱社会秩序的；
> （六）宣扬封建迷信、淫秽、色情、赌博、暴力、凶杀、恐怖、教唆犯罪的；
> （七）公然侮辱他人或者捏造事实诽谤他人的；
> （八）损害国家机关信誉的；
> （九）其他违反宪法和法律、行政法规的。
> 第20条规定：
> 违反法律、行政法规，有本办法第五条、第六条所列行为之一的，由公安机关给予警告，有违法所得的，没收违法所得，对个人可以并处5000元以下的罚款，对单位可以并处1.5万元以下的罚款……构成违反治安管理行为的，依照治安管理处罚条例的规定处罚；构成犯罪的，依法追究刑事责任。

从严格的法律角度来说，翻墙访问被禁止的网页或服务涉嫌违法，违法行为如何处罚要根据具体的情节和危害程度来定，一般而言，对于绝大多数翻墙用户来说，若只是浏览信息，并没有散布行为，一般不予处罚，如果对于被禁止的网页和服务进行散布和传播(如讨论和散布有关邪教和敏感的政治话题，教授和他人如何翻墙)理论上构成犯罪，然而如果提供翻墙服务，则一定是违法并且犯罪，并且一定会承担法律后果

近年来国民对于国家的认可和拥护程度变高、中国在国际社会上地位的大幅提升、翻墙人品基数过于庞大导致执法成本远远超过实际，这三个因素共同作用导致我们这些不会造成实际危害的普通翻墙用户不需要在过纠结从法律上来讲翻墙的违法事实是否会导致我们受到处罚

# 关于敏感时期

每年到5、6月的时候，中国的国家利益和稳定会受到来自外部，包括很多西方国家和国内一些别有用心的组织内外夹击，有舆论上的，也有行动上的，GFW的审查也会加大力度甚至会有人工干预，很多能正常访问的国际网站和服务都会在这段时间内被临时性的封闭；除此之外，大批量的机场IP、VPS供应商的IP段，以及VPN的服务器IP也会被大量封锁

这段时间会有一个特别的现象，大量的小机场会跑路，一些小机场确实是因为被封锁了IP，他们更换IP需要的资源和手段往往也被限制了，这各情况下，一些良心的小机场，会通知你，另一种情况下，很多小机场干脆就降价促销，大卖一波，直接拿着收到的年费直接跑路

建议在7月后购买年付的机场，要自己鉴别，大机场也有可能跑路

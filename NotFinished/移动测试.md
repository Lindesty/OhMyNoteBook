## 自动化测试

### 定义 

- 以自动化的方式对app进行充分的功能历以探索bug

### 价值

- 降低自动化维护成本，可替代80%的自动化测试

- 实现新功能的探索

- 实现老功能的回归

- 多设备兼容测试、自动化专项测试

### 合理的自动化策略

- 单元测试：使用App分层测试策略，增加单测规模，控制UI自动化测试规模。

- 移动App自动化测试：核心集成与验收测试用例交给自动化测试。

- 自动遍历测试：大部分的基础回归测试交给自动遍历。

- 人工测试：测试团队主负责，整个产品团队参与。

## Android

### adb

- 常用命令

	- adb devices

		- 查看设备

	- adb kill-server

		- 关闭adb的后台进程

	- adb tcpip

		- 让Android脱离USB线的TCP连接方式

	- adb connect

		- 连接开启了TCP连接方式的手机

	- adb logcat

		- Android日志查看

	- adb bugreport

		- 收集日志数据，用于后续的分析，比如耗电量

- 全称

	- Android Debug Bridge

### adb shell

- adb shell本身就是一个Linux的shell，可以调用Android内置命令

- 命令

	- adb shell dumpsys

		- 获取应用的各种信息

			-  

		-  adb shell "dumpsys window | grep mCurrentFocus"

			- 获取当前的窗口activity

	- adb shell pm

		- adb install

			- 安装应用

		- adb shell pm clear com.baidu.tieba

			- 清理应用的所有缓存数据

	- adb shell am

		- activity管理工具

		-  adb shell am start -n com.baidu.tieba/.tblauncher.MainTabActivity -S    

			- 调用应用的activity

	- adb shell ps

		- 了解进程列表

	- adb shell monkey

		- 兼容性测试工具

	- adb shell uiautomator

		- adb shell "uiautomator dump && cat /sdcard/window_dump.xml" 

			- 获取界面并把界面转化为xml并在控制台输出

		- adb shell uiautomator runtest

	- adb shell input

		- 模拟操作
